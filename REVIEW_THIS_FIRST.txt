VolunteerLink - Organisation base addition
=========================================

Purpose
-------
1. Add a temporary FIRST PAGE (not login) with:
   - Continue as Volunteer -> existing VolunteerOpportunityNavigationHost
   - Continue as Organisation -> new OrganisationNavigationHost
2. Add Organisation pages:
   - Home
   - Manage
   - Create
   - Chats
   - Profile
3. Add a reusable Organisation bottom-navigation design using the existing
   VolunteerLink colour constants already declared in ui/theme/Color.kt.
4. Keep the existing Volunteer module untouched.

Existing files intentionally modified
-------------------------------------
- app/src/main/java/com/example/volunteerlink/MainActivity.kt
  Only changes the app entry point from the Volunteer host to AppNavGraph
  and removes old unused Supabase-test imports.

- app/src/main/java/com/example/volunteerlink/navigation/AppBottomNavigationBar.kt
  Reuses the existing VolunteerLink colours from Color.kt and keeps the
  navigation bar design reusable.

Notes
-----
- Organisation pages currently use fixed placeholder content similar to the
  existing temporary Volunteer pages.
- No ViewModel or Repository was added because these pages currently have no
  mutable/business data.
- When future pages contain growing lists, use LazyColumn/LazyRow instead of
  placing a large number of items in Column/Row.
